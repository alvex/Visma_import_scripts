visma_import.py

Automatisk registrering av kundfakturor i Visma Compact

Det här dokumentet visar hur du installerar och använder visma_import.py. Scriptet läser en Excel-fil och registrerar kundfakturor i Visma Compact (Kundbokning) automatiskt genom att styra mus och tangentbord.

Så fungerar det kort För varje rad i Excel klickar scriptet i rätt fält i Visma, skriver in värdena och sparar med Num+. Fakturanumret skapas av Visma; du anger själv vilket nummer serien börjar på och det kontrolleras mot Excel innan körningen startar.

1. Förutsättningar

  • Windows med Python 3 installerat.
  • Visma Compact installerat och inloggat.
  • En Excel-fil med fakturorna (se avsnitt 3).
  • Scriptet visma_import.py ligger i C:\ekonomi\scripts.

2. Installation

1

Kontrollera Python

Öppna PowerShell (tryck Win + R, skriv powershell, Enter) och kör:

python --version

Får du ett versionsnummer (t.ex. Python 3.12) är Python installerat.

2

Installera nödvändiga paket

Kör en gång:

pip install pandas pyautogui openpyxl
  • pandas + openpyxl – läser och skriver Excel.
  • pyautogui – styr mus och tangentbord.

3. Förbered Excel-filen

Filen måste innehålla dessa kolumner (rubrikerna på första raden):

KolumnInnehållGodkända alternativa namn
KundIDKundens ID / personnummer, t.ex. 830930-7596Personnummer, Kundnummer
FakturanrFakturanummer, t.ex. 48991 (heltal)Fakturanummer, Faktura nr, Faktura Nr, FakturaNr
FakturadatumDatum, t.ex. 2026-06-15Faktura datum
BeloppFakturabelopp, t.ex. 1845 eller 1845,50Fakturabelopp
Bra att veta
  • Datum konverteras automatiskt till Vismas format YY-MM-DD (2026-06-15 blir 26-06-15).
  • Belopp konverteras till svenskt format med komma (1845 blir 1845,00).
  • Lägg raderna i samma ordning som Visma skapar fakturanumren – ett nummer per rad, i löpande följd.

4. Innan du kör

  1. Öppna Visma Compact → Kundreskontra → Kundbokning.
  2. Maximera Visma-fönstret (samma läge varje gång – scriptet klickar på fasta positioner i fönstret).
  3. Se till att fakturaformuläret visas (fälten Kund ID, Bokf.dag, Fak.belopp syns).
  4. Stäng eventuella popup-fönster i Visma.
Om värden hamnar i fel fält Scriptet klickar på positioner som anges högst upp i visma_import.py (KUNDID_*, BOKFDAG_*, FAK_BELOPP_*). Om din skärm/upplösning skiljer sig kan ett klick missa fältet. Justera då siffrorna där tills klicken träffar mitt i respektive fält. X_RATIO är andel av fönstrets bredd (0–1), Y är pixlar från fönstrets överkant.

5. Kör scriptet – steg för steg

1

Starta scriptet

I PowerShell:

cd C:\ekonomi\scripts
python visma_import.py
2

Ange Excel-filen

Ange sökväg till Excel-filen: C:\Ekonomi\Fak 2026\April\fakturor.xlsx

Du kan klistra in hela sökvägen. Ändelsen .xlsx läggs till automatiskt om den saknas.

3

Ange antal och startnummer

Excel innehåller 20 poster.
Hur många fakturor ska registreras? (1-20): 5
Starta från Fakturanr: 48995

Scriptet hittar raden med Fakturanr = 48995 och registrerar 5 poster därifrån och framåt (48995–48999). Max 50 per körning.

4

Bekräfta och starta

Scriptet visar en sammanfattning och att Visma hittats. Tryck Enter för att starta. En nedräkning från 3 börjar – ta bort händerna från mus och tangentbord.

Tryck Enter för att starta...
Startar om 3...
Startar om 2...
Startar om 1...
5

Låt scriptet arbeta

Scriptet styr nu musen och skriver i Visma helt själv. Rör inte datorn under tiden.

Nödstopp Behöver du avbryta direkt: flytta muspekaren snabbt till skärmens övre vänstra hörn. Då stoppar scriptet omedelbart (PyAutoGUI failsafe) och ingen mer faktura sparas.

6. Flödet per faktura

Kund ID  →  Bokf.dag (datum)  →  Fak.belopp  →  5 × Tab  →  kort paus  →  Num+

För varje rad: kunden laddas via KundID, datumet skrivs i Bokf.dag, beloppet i Fak.belopp, därefter 5 Tab och till sist Num+ som sparar fakturan i Visma. Fakturanumret sätts av Visma automatiskt.

Pausen före Num+ Inställningen PAUSE_BEFORE_NUM_PLUS (standard 1.0 sekund) ger en kort paus precis innan fakturan sparas. Höj värdet om du vill hinna se fälten innan varje sparning.

7. Loggfilen

Efter körningen sparas en loggfil i samma mapp som Excel-filen:

visma_import_logg_ÅÅÅÅMMDD_TTMMSS.xlsx

Loggen innehåller en rad per behandlad faktura med bl.a.: Rad, KundID, Excel Fakturanr, Visma Fakturanr, Status (OK / STOPPAD) och Fel. Kontrollera alltid loggen efter en körning.

8. Felsökning

Meddelande / symptomOrsak & åtgärd
FEL: Visma Compact hittades inte. Visma är inte öppet på Kundbokning. Öppna Kundreskontra → Kundbokning och kör igen.
Filen hittades inte Fel sökväg till Excel. Kontrollera sökvägen; testa att klistra in den utan citattecken.
Fakturanr X finns inte i Excel Startnumret matchar ingen rad. Kontrollera att numret finns i kolumnen Fakturanr.
FÖR FÅ POSTER FRÅN STARTNUMRET Du bad om fler fakturor än det finns rader kvar från startnumret. Välj lägre antal eller tidigare startnummer.
Värden hamnar i fel fält (t.ex. beloppet i Info) Klickpositionerna stämmer inte med din skärm. Justera KUNDID_*, BOKFDAG_*, FAK_BELOPP_* högst upp i scriptet (se avsnitt 4).
Datumet blir fel i Bokf.dag Datumet konverteras alltid till YY-MM-DD. Kontrollera att Excel-datumet är ett giltigt datum.
Scriptet stannar mitt i Titta i loggfilen: kolumnen Fel visar orsaken för den rad där det stoppade. Ingen faktura efter felet sparas.

9. Säkerhetsråd

  • Testa med 1 faktura först och kontrollera i Visma att alla fält blev rätt innan du kör hela serien.
  • Rör inte mus/tangentbord medan scriptet arbetar.
  • Ha alltid nödstoppet i åtanke: mus till övre vänstra hörnet.
  • Granska loggfilen efter varje körning.
  • Se till att Excel-serien är korrekt och i rätt ordning – scriptet litar på att raderna följer Vismas nummerserie.
